Detailed Description

template<typename T, Routing RoutingType = Routing::Series>
class jnsc::StateVariableFilter< T, RoutingType >

Multi-channel TPT state variable filter with sample-by-sample frequency and Q inputs. Supports multiple second-order sections with series or parallel routing. Parameter storage and smoothing belong to the caller.

Template Parameters
TSample data type (e.g., float, double).
RoutingTypeFilter routing type (Series or Parallel).

Parameters

Note
