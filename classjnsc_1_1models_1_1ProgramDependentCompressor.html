Detailed Description

template<typename T, EnvelopeType EnvelopeType = EnvelopeType::RMS>
class jnsc::models::ProgramDependentCompressor< T, EnvelopeType >

Feedforward compressor whose attack, release, ratio, and knee can depend on its current gain reduction.

Template Parameters
TSample type
EnvelopeTypeType of envelope follower (default: RMS)
