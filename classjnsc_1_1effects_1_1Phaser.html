Detailed Description

template<typename T>
class jnsc::effects::Phaser< T >

Phaser audio effect using a modulated TPT all-pass cascade. Two second-order sections at Q = 0.5 provide four first-order phase shifts. The cascade is blended equally with the input to create two sweeping notches.
