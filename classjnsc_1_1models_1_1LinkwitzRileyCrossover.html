Detailed Description

template<typename T>
class jnsc::models::LinkwitzRileyCrossover< T >

Two-band, second-order Linkwitz-Riley crossover (12 dB/octave).

Uses independent lowpass and highpass sections of one biquad filter, with Q = 0.5 at a shared frequency. The high output is polarity-inverted so that low + high has unity magnitude. The sum is allpass, not an unchanged copy of the input waveform.
